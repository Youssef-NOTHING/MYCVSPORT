# 🏀 Youssef's Basketball Portfolio

A modern, responsive sports portfolio website showcasing basketball skills, achievements, and professional aspirations.

## ✨ Features

- **Enhanced Background Video**: Parallax scrolling, mobile optimization, battery saving
- **Animated Testimonials**: Interactive testimonial cards with profile pictures  
- **Professional Contact Form**: Real-time validation and form submission
- **Media Gallery**: Photo and video showcase with upload functionality
- **Responsive Design**: Optimized for all devices and screen sizes
- **Basketball Goals**: Detailed aspirations for European teams and professional development

## 🚀 Quick Start with npm

### Prerequisites
- Node.js (version 16 or higher)
- npm (version 8 or higher)

### Installation & Setup

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start the application**
   ```bash
   npm start
   ```

   The application will run on: http://localhost:3000

### Available Scripts

- `npm start` - Start the production server
- `npm run dev` - Start development mode with hot reload  
- `npm run backend` - Start only the backend server
- `npm run frontend` - Start only the frontend server
